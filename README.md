This is a simple typed JSON object store persisting each object into a single json file. This package was written and published for usage in [llm-chat-memory](https://github.com/johanneslatzel/llm-chat-memory) and [llm-chat-task](https://github.com/johanneslatzel/llm-chat-task).

> **Disclaimer**: This package was written entirely by AI. Use at your own risk.

## Features

- typed object store
- json file persistence with one file per object

## Prerequisites

- Node.js >= 18

## Installation

```bash
npm install @johannes.latzel/json-file-store
```
